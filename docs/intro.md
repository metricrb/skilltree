# Overview

**SkillTree** is a Roblox library (strict Luau) for data-driven skill trees: unlock costs, prerequisites, multi-rank nodes, exclusive groups, and several layout modes.

- **Guides** (this section) cover install, wiring, and config shape.
- **API** lists every public class, method, and type extracted from source.

If you only need types and signatures, open **[Types](/api/Types)** and **[SkillTree](/api/SkillTree)** first.
